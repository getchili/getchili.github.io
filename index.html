● v0.1 — ESP32

Le langage qui pimente ton ESP32.

Chili est un petit langage pour microcontrôleurs. Écris ton programme, envoie-le à la carte par USB ou WiFi en une commande. Pas d'IDE, pas de reflash, pas d'attente.

Télécharger Chili pour Windows Voir sur GitHub
blink.chl
// fait clignoter la LED de la carte
let led = 2

class Main {
    function main() {
        gpio.mode(led, 1)
        while true {
            gpio.write(led, 1)
            delay(500)
            gpio.write(led, 0)
            delay(500)
        }
    }
}

Pourquoi Chili

Tout tient dans un seul outil.

Un exécutable, une carte, un câble. Chili s'occupe de détecter la carte, d'installer son firmware et d'y envoyer tes programmes.

⚡

Envoi instantané

Le firmware est installé une seule fois. Ensuite, chaque programme part en une fraction de seconde, sans recompiler le firmware.

📡

Avec ou sans fil

Par USB, ou par WiFi une fois la carte connectée au réseau : chili push blink.chl 192.168.1.42.

🪶

Ultra léger

Une VM en C sans allocation dynamique, avec un ramasse-miettes pour les objets. Le gros du travail est fait par le compilateur, sur ton PC.

🛡️

Sûr par défaut

Le bytecode est vérifié avant d'être lancé. Une division par zéro arrête le programme proprement, sans planter la carte.

Démarrer

De la boîte à la LED qui clignote.

Il te faut un ESP32, un câble USB de données et Windows. L'installateur s'occupe du reste, sans droits administrateur.

Installe Chili

Lance ChiliSetup.exe : la commande chili devient disponible dans tous tes terminaux.

chili version

Branche la carte

Chili la détecte et t'affiche le modèle de puce, son état et la marche à suivre.

chili check-port

Installe le firmware

Une seule fois par carte, environ 30 secondes. Le firmware est inclus dans chili.exe.

chili flash

Envoie ton code

Le programme est compilé, envoyé, lancé, et il redémarre tout seul à chaque mise sous tension.

chili push blink.chl
🧪

Chili Lab, l'application de bureau

Pas envie du terminal ? Chili Lab détecte la carte, installe le firmware, envoie tes programmes et affiche leur sortie, le tout à la souris. Glisse un .chl, c'est parti.

Le langage

Simple à lire, rapide à écrire.

Une syntaxe à accolades sans points-virgules, des entiers 32 bits, des fonctions, des boucles et des classes. Juste ce qu'il faut pour piloter du matériel.

Classes et objets

class Led {
    let broche

    constructor(b) {
        this.broche = b
        gpio.mode(b, 1)
    }

    function allume(ms) {
        gpio.write(this.broche, 1)
        delay(ms)
        gpio.write(this.broche, 0)
    }
}

Fonctionnement

Compilé sur ton PC, exécuté sur la carte.

Le compilateur (en Go) transforme ton code en bytecode compact. La carte n'a qu'à l'exécuter : c'est ce qui rend Chili léger et rapide à envoyer.

blink.chlTon programme, en texte.
→
chiliAnalyse, vérifie et compile sur le PC.
→
blink.chlbBytecode de quelques centaines d'octets, protégé par CRC.
→
